SYBIL STUDIO DOCUMENTATION

Sybil Studio - Dart Web IDE

Sybil Studio is a browser-based Dart Web IDE developed by Omrani Research Industries. It is a first real multi-file Dart-Web Online IDE. It provides a simple environment for writing, running, saving, and previewing Dart web applications directly from a web browser.

Sybil Studio is designed to make Dart web development easier to experiment with by bringing the editor, project files, execution controls, preview, and output together in one interface.

Welcome to Sybil Studio. This documentation explains the main editor features, file structure, controls, keyboard shortcuts, preview system, and basic workflow for creating Dart web applications.

1. Getting Started

1.1. Opening Sybil Studio

Sybil Studio runs in a web browser. No traditional desktop IDE installation is required to use the editor interface.

After opening Sybil Studio, the main editor provides the tools required to work with a small Dart web project.

The basic workflow is:

  • Open Sybil Studio.
  • Choose a project file.
  • Write or modify the code.
  • Run the project.
  • Inspect the Preview and OUTPUT panels.
  • Save your work when needed.

1.2. Your First Dart Program

A simple Dart program can begin with a main() function.

void main() { print('Hello from Sybil Studio!'); }

Press Ctrl + Enter to run the project.

2. Sybil Studio Interface

2.1. Header

The Sybil Studio header identifies the editor and provides access to the main editor controls.

The editor is presented as:

Sybil Studio - Dart Web IDE

The interface also identifies Sybil Studio as an Omrani Research Industries product.

2.2. Toolbar

The toolbar contains the primary actions used while working on a project.

The available controls are:

  • Run - compile and run the current project.
  • Save - save the current editor contents.
  • Clear - clear the current editor content.
  • + New File - create a new project file.

2.3. File Tabs

Sybil Studio provides tabs for the main project files.

The standard editor includes:

  • main.dart
  • index.html
  • styles.css

Selecting a tab changes the active file in the editor.

3. Project Files

3.1. main.dart

The main.dart file contains the Dart source code for the application.

A basic Dart web application can start with:

import 'dart:html'; void main() { print('Hello from Sybil Studio!'); }

The Dart language provides the programming logic used by the application.

3.2. index.html

The index.html file provides the HTML document used by the web application.

<!DOCTYPE html> <html> My Dart App <h1>Hello from Dart Web</h1>

HTML defines the structure and content of the web page.

3.3. styles.css

The styles.css file controls the visual appearance of the web page.

body { font-family: Arial, sans-serif; padding: 40px; } h1 { font-size: 32px; }

CSS can be used to change fonts, spacing, dimensions, positioning, colors, borders, and other visual properties.

4. The Code Editor

4.1. Writing Code

The main editor is where the active project file is edited. Dart source code, HTML, and CSS can be modified depending on the selected file.

The editor is designed to provide a simple environment for experimenting with Dart web applications without requiring a large development environment.

4.2. Line Numbers

Sybil Studio displays line numbers alongside the editor. Line numbers make it easier to identify the location of code and errors.

4.3. Tab Key

Pressing the Tab key inside the editor inserts four spaces.

Tip: Consistent indentation makes Dart, HTML, and CSS code easier to read and maintain.

5. Running a Project

5.1. Run Button

The Run button starts the compilation and execution process for the current project.

When the project is successfully processed, the result can be displayed in the Preview panel.

5.2. Keyboard Shortcut

You can run the project without clicking the toolbar by pressing:

Ctrl + Enter

This shortcut is useful when repeatedly testing changes.

6. Preview

6.1. Preview Panel

The Preview panel displays the resulting web application inside the Sybil Studio interface.

This allows HTML, CSS, and Dart changes to be tested without leaving the editor.

6.2. Testing Web Interactions

Web applications can contain interactive HTML elements that respond to Dart events.

For example, a button can be defined in HTML:

<button id="hello"> Say Hello </button>

Dart can then attach an event listener to the button.

import 'dart:html'; void main() { final button = querySelector('#hello'); button?.onClick.listen((event) { window.alert('Hello from Dart!'); }); }

7. OUTPUT Panel

7.1. Program Output

The OUTPUT panel displays information produced during the execution process.

For example:

void main() { print('Hello from Sybil Studio!'); }

The printed message can appear in the output area after running the project.

7.2. Errors

If the compiler or execution process encounters an error, information about the error can be displayed in the OUTPUT panel.

Use the reported information to locate the problem in the relevant file and line.

8. Saving Your Work

8.1. Save Button

The Save button stores the current editor contents.

Sybil Studio also uses browser storage to preserve editor content between sessions where supported by the browser.

8.2. Save Shortcut

The keyboard shortcut for saving is:

Ctrl + S

9. Creating a New File

The + New File button allows another project file to be created.

New files can be used to organize additional Dart, HTML, or CSS source code as the project grows.

Tip: Keep files organized according to their purpose. Dart files should contain application logic, HTML files should define document structure, and CSS files should contain presentation rules.

10. Clearing a File

The Clear button removes the contents of the active editor.

Important: Be careful when using Clear. Make sure you have saved anything you want to keep before removing the contents of a file.

11. Building a Simple Web Application

11.1. HTML

Begin by creating a simple HTML structure.

<h1 id="title"> Hello from Dart Web </h1>

11.2. CSS

Add styling to the page.

body { font-family: Arial, sans-serif; padding: 40px; } button { padding: 10px 20px; }

11.3. Dart

Dart can connect the HTML interface to application logic.

import 'dart:html'; void main() { final button = querySelector('#hello'); final title = querySelector('#title'); button?.onClick.listen((event) { if (title != null) { title.text = 'Hello from Dart!'; } }); }

11.4. Run the Application

Press Ctrl + Enter or click Run.

The application should appear in the Preview panel.

12. Browser Storage

Sybil Studio uses browser storage to preserve editor content. The editor maintains separate storage for its project files.

The standard storage entries correspond to:

  • main.dart
  • index.html
  • styles.css

This allows the editor contents to remain available when the user returns to the editor in the same browser environment.

13. Keyboard Shortcuts

Sybil Studio provides several keyboard shortcuts for common operations.

  • Ctrl + Enter - Run the project.
  • Ctrl + S - Save the current project.
  • Tab - Insert four spaces in the editor.

14. Dart Web Development

Sybil Studio is designed around Dart web development. Dart supports web applications and provides access to browser functionality and JavaScript interoperability.

Modern Dart web development commonly uses package:web for browser APIs, while older projects may use libraries such as dart:html. The current Dart documentation describes package:web as the recommended web interop solution.

Sybil Studio examples may use the APIs supported by its current compiler and project configuration.

15. Compilation

Dart web applications must be compiled before the browser can execute the resulting web application.

Dart's web tooling provides development and production compilation workflows for web applications.

In Sybil Studio, the compilation process is integrated into the editor workflow so that users can focus on writing and testing their application.

16. Debugging

16.1. Finding Problems

When an application does not behave as expected, first check the OUTPUT panel for compiler or execution information.

Then inspect:

  • The active Dart file.
  • HTML element identifiers.
  • CSS selectors.
  • Event listeners.
  • Imports.
  • Syntax and brackets.

16.2. Browser Developer Tools

Browser developer tools can also be useful when debugging web applications, especially for inspecting HTML, CSS, browser errors, and application behavior.

Dart's official debugging documentation also describes using Dart DevTools and browser developer tools for debugging Dart web applications.

17. Common Problems

17.1. The Preview Is Empty

Check that the HTML file contains valid content and that the Dart application has successfully compiled.

Also check the OUTPUT panel for errors.

17.2. A Button Does Nothing

Verify that the ID used by the Dart code exactly matches the ID used by the HTML element.

<button id="hello"> Click Me </button>
final button = querySelector('#hello');

17.3. CSS Changes Are Not Visible

Check that the stylesheet is correctly connected to the HTML document.

<link rel="stylesheet" href="styles.css" >

17.4. Dart Code Does Not Compile

Read the error shown in the OUTPUT panel and inspect the indicated source location.

Common causes include syntax errors, incorrect imports, invalid types, missing elements, and unsupported APIs.

18. Recommended Workflow

A simple development workflow can make projects easier to understand and debug.

  • Start with a small HTML structure.
  • Add CSS after the structure works.
  • Add Dart logic one feature at a time.
  • Run the project frequently.
  • Read the OUTPUT panel after each failed run.
  • Use meaningful names for HTML elements and Dart variables.
  • Keep related functionality organized.
  • Save your work regularly.

19. Example Project

A simple Sybil Studio project can consist of three files.

main.dart

import 'dart:html'; void main() { final button = querySelector('#hello'); final message = querySelector('#message'); button?.onClick.listen((event) { if (message != null) { message.text = 'Hello from Sybil Studio!'; } }); }

index.html

<!DOCTYPE html> <html> <title>My Sybil Studio App</title> <link rel="stylesheet" href="styles.css" > <h1 id="message"> Welcome to Sybil Studio </h1> <button id="hello"> Say Hello </button>

styles.css

body { font-family: Arial, sans-serif; padding: 40px; } button { padding: 10px 20px; cursor: pointer; }

20. Learning With Sybil Studio

Sybil Studio can be used to experiment with Dart programming and browser-based web development.

Beginners can start with simple programs and gradually introduce functions, collections, classes, events, HTML, CSS, and asynchronous programming.

More experienced developers can use the editor to prototype ideas and create small interactive Dart web applications.

21. Project Limitations

Sybil Studio is designed as a browser-based development environment. It should not be considered a complete replacement for a full local Dart development environment for every type of project.

Larger applications may require a local project structure, additional dependencies, testing tools, build tools, version control, and deployment infrastructure.

The capabilities available in Sybil Studio depend on its current compiler, browser environment, and project configuration.
